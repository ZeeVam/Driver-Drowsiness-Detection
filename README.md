# Real-Time Driver Drowsiness Detection

A computer vision project developed in Python that monitors a driver in real-time to detect signs of drowsiness and sounds an alarm if detected. This project is designed to improve road safety by preventing accidents caused by driver fatigue.

![Demo GIF of the project in action](https://github.com/ZeeVam/Driver-Drowsiness-Detection/raw/main/demo.gif)

---

## Features
* **Real-Time Face & Eye Tracking:** Utilizes dlib's facial landmark prediction to accurately track the driver's eyes in real-time from a webcam feed.
* **Drowsiness Detection:** Employs a custom-trained Convolutional Neural Network (CNN) built with TensorFlow/Keras to classify eye states as 'Open' or 'Closed'.
* **Audible Alarm System:** If the driver's eyes remain closed for a predetermined duration, the system triggers an audible alarm to alert the driver.
* **Lightweight & Efficient:** The model and detection logic are optimized to run smoothly on a standard consumer-grade laptop.

---

## Tech Stack
* **Language:** Python
* **Libraries:**
    * **OpenCV:** For real-time video capture and image processing.
    * **TensorFlow / Keras:** For building and training the CNN model for eye state classification.
    * **Dlib:** For high-performance face detection and facial landmark prediction.
    * **NumPy:** For numerical operations and image manipulation.
    * **Pygame:** For playing the alarm sound.

## Setup and Installation

To run this project locally, follow these steps:

**1. Clone the Repository:**
```bash
git clone [https://github.com/ZeeVam/Driver-Drowsiness-Detection.git](https://github.com/ZeeVam/Driver-Drowsiness-Detection.git)
cd Driver-Drowsiness-Detection
```

**2. Install Dependencies:**
It is recommended to use a virtual environment. All required libraries are listed in `requirements.txt`.
```bash
pip install -r requirements.txt
```

**3. Download the Shape Predictor Model:**
The facial landmark detector from dlib is required. Download it from [this link](http://dlib.net/files/shape_predictor_68_face_landmarks.dat.bz2), unzip it, and place the `shape_predictor_68_face_landmarks.dat` file in the main project directory.

---

## Usage

**1. Train the Model:**
Before running the detector, you must first train the model. The dataset is not included in this repository to keep it lightweight. Please download the eye-state dataset from a source like Kaggle and place the `train` folder (containing `Open` and `Closed` subfolders) in the root of the project directory. The trained model file (`drowsiness_model.h5`) will be generated by this script.
```bash
python train_model.py
```

**2. Run the Detector:**
Once the model is trained and `drowsiness_model.h5` has been created, you can run the main application.
```bash
python detect_drowsiness.py
```
Ensure you are in a well-lit environment for optimal performance.
